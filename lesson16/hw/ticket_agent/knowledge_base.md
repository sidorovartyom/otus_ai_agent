# База знаний: технические проблемы Otus Cloud (для агента поддержки)

## Ошибка Connection timeout при подключении к хранилищу
Причина - устаревший регион эндпоинта. Решение: обновить endpoint на
storage.otus-cloud.example/eu-central и переподключиться.

## Файлы зависают в статусе pending и не синхронизируются
Известная проблема воркера синхронизации. Решение: перезапустить
синхронизацию кнопкой Resync в личном кабинете; если не помогло -
обратиться в поддержку с логом ошибки.

## Превышена квота API запросов, ошибка 429 Too Many Requests
Лимит - 1000 запросов в минуту на тарифе Business. Решение: включить
экспоненциальный backoff на стороне клиента или перейти на тариф
Enterprise, где лимит выше.
