# otus_ai_agent

# Домашнее задание: Память агента

## Описание
Реализация системы памяти агента с гибридным поиском на основе футбольных данных.
Система объединяет векторный поиск (семантический) и графовый поиск (по связям между объектами).

## Реализованный функционал

### 1. Векторный поиск
- Получение эмбеддингов через API (text-embedding-ada-002)
- Вычисление косинусного сходства между запросом и документами
- Поиск top-k наиболее релевантных документов

### 2. Графовое хранение
- Использование `networkx` для хранения графа знаний в памяти
- Узлы: игроки, клубы, тренеры, лиги
- Связи: PLAYED_FOR, COACHED, PLAYS_IN, COMPETES_WITH
- Навигация по связям между объектами

### 3. Гибридный поиск
Комбинирует два подхода:
1. **Векторный поиск** → находит семантически релевантные документы
2. **Извлечение сущностей** → определяет упомянутые объекты в найденных документах
3. **Обогащение контекста** → добавляет связи из графа знаний для найденных сущностей

## Структура данных

### Документы (6 исторических футбольных статей)
1. Трансфер Роналду в Реал Мадрид (2009)
2. Чудо в Стамбуле: финал ЛЧ 2005
3. Золотая эра Барселоны при Гвардиоле (2008-2012)
4. Триумф Ливерпуля под руководством Клоппа (2019-2020)
5. Легенда Зидана: от игрока до тренера
6. Непобедимые Арсенала сезона 2003-04

### Граф знаний
- **23 узла**: 10 игроков, 6 клубов, 4 тренера, 3 лиги
- **25 связей**: игроки-клубы, тренеры-клубы, клубы-лиги, конкуренция

## Примеры работы

### Запрос 1: "Какие достижения у Роналду в Реале?"

**Векторный поиск нашел:**
- "Трансфер Роналду в Реал Мадрид" (сходство: 0.871)
- "Легенда Зидана" (сходство: 0.837)

**Граф добавил связи:**
- Роналду → PLAYED_FOR → Реал Мадрид (2009-2018)
- Роналду → PLAYED_FOR → Манчестер Юнайтед (2003-2009)
- Реал Мадрид → COMPETES_WITH → Барселона (El Clasico)
- Зидан → COACHED → Реал Мадрид (2016-2018)

**Преимущество гибридного поиска:**
Векторный поиск нашел релевантный текст, а граф добавил структурированную информацию о клубной карьере Роналду, которая не была явно упомянута в документе о достижениях.

## Технические детали

### Архитектура
```
agent_memory.py
├── Конфигурация (загрузка .env, создание клиента)
├── Данные
│   ├── DOCUMENTS - список документов с метаданными
│   └── build_knowledge_graph() - построение графа
├── Векторный поиск
│   ├── get_embedding() - получение эмбеддингов
│   ├── cosine_similarity() - вычисление сходства
│   └── vector_search() - поиск по документам
├── Графовый поиск
│   ├── find_related_entities() - поиск связанных объектов
│   ├── find_entities_by_type() - фильтр по типу
│   └── graph_search() - навигация по графу
├── Гибридный поиск
│   ├── hybrid_search() - объединение двух подходов
│   └── format_context_for_llm() - форматирование для LLM
└── main() - демонстрация работы
```

### Используемые библиотеки
- `numpy` - операции с векторами
- `networkx` - графовая БД в памяти
- `openai` - API для эмбеддингов
- `httpx` - HTTP клиент с поддержкой сертификатов
- `python-dotenv` - загрузка переменных окружения
